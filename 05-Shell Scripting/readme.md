
# Shell Scripting

## Objective

The objective of this lab is to learn the basics of Shell Scripting and perform simple tasks using Bash scripts.

## Theory

Shell scripting is a way to automate tasks in the Linux operating system. A shell script is a text file containing a sequence of commands that are executed by the shell.
